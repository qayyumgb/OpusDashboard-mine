Break notification
Notify the worker that an Auto break is started by vibrating the watch. When the worker falls within a worker group of an Auto break enabled break scheme option the worker receives a notification message the break is started and watch vibrates. Enable break notifications
Break Scheme
When Auto is enabled and the presence time falls between the Start and End time a break will be automatically created at the break time moment with a certain duration in minutes. The break can be set to paid or unpaid. When the Device break is enabled the break type will be set accordingly to the period (start/stop time) in which the break falls. By default it’s paid if it’s not set. Break time is based on the registration on the device.
